### 📚 Learning Roadmap

| Topic | Concepts |
|---|---|
| JavaScript Fundamentals | Variables, conditions, loops, functions, scope |
| Arrays | Traversal, searching, transformations, two pointers |
| Array Methods | `map`, `filter`, `reduce`, `find`, `some`, `every` |
| Objects | Keys, values, entries, nested objects, object manipulation |
| Strings | Character operations, frequency counting, palindrome checks |
| Recursion | Base cases, recursive calls, call stack |
| Searching & Sorting | Linear search, binary search, sorting algorithms |
| Data Structures | Stacks, queues, linked lists, hash maps, trees |
| Algorithms | Two pointers, sliding window, recursion, backtracking |
| Complexity Analysis | Time complexity and space complexity |

### 🔬 My Problem-Solving Workflow

```text
Understand the problem
        ↓
Identify inputs and expected output
        ↓
Develop a logical approach
        ↓
Write a solution in JavaScript
        ↓
Test normal and edge cases
        ↓
Analyze time and space complexity
        ↓
Refactor and improve
```

**DSA principle:** First understand why a solution works. Then optimize it.
